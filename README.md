# MyStuff

A private, encrypted vault for passwords, notes, cards, IDs and documents, by Ravvo.

- Website: https://ravvo-717.github.io/mystuff/
- Privacy policy: https://ravvo-717.github.io/mystuff/privacy.html
- Downloads: see [Releases](https://github.com/ravvo-717/mystuff/releases)

## Website development

```bash
npm install
npm run dev      # local preview
npm run build    # production build in dist/
```

Pushing to `main` publishes the site to GitHub Pages.
